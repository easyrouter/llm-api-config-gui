# Base URL、API Key 和模型名：配置 AI API 前先分清三件事

[返回首页](../../README.md) · [快速开始](../QUICKSTART.md)

| 名称            | 作用                     | 常见误填                                 |
| --------------- | ------------------------ | ---------------------------------------- |
| Base URL        | 告诉客户端请求发送到哪里 | 填成官网登录页、文档页或完整请求接口     |
| API Key         | 向服务商证明请求权限     | 使用其他服务商的 Key，或复制了空格、引号 |
| Model / 模型 ID | 告诉服务商调用哪个模型   | 填成宣传名称，或使用账户没有权限的模型   |

三者必须匹配。协议也必须匹配：支持 Chat Completions 不等于支持 Responses 或 Anthropic Messages。

## 为什么有些地址要带 /v1，有些不要？

客户端拼接请求路径的方式不同。本项目的 SeedRouter 预设中，Codex 使用 `https://seedrouter.net/v1`，Claude Code 使用 `https://seedrouter.net`。这不是所有 API 服务的统一规则。

修改前先确认客户端和服务商文档，不要靠反复添加、删除 `/v1` 试错，更不要向不认识的地址发送密钥。

## 可以使用其他服务商吗？

可以。修改地址、模型和密钥，确认目标服务商支持客户端需要的协议，再运行连接测试。SeedRouter 是默认预设与赞助方，不是强制绑定。

## 配置正确是否就免费？

不是。开源配置工具的许可证和 API 调用计费是两回事。连接测试也可能产生用量费用；请在所选服务商控制台查看价格、限额和余额。
